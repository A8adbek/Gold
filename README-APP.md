# Gold Widget

Samsung va boshqa Android telefonlar uchun XAUUSD bosh ekran vidjeti.

## Imkoniyatlar

- Rasmdagidek oq, yumaloq 4x2 vidjet
- XAUUSD narxi, vaqt va kunlik o‘zgarish
- Avtomatik 10 soniyalik yangilanish
- Qo‘lda yangilash tugmasi
- Exness narxiga moslash uchun korrektirovka
- VPS/MT5 Exness oqimiga keyin ulashga tayyor
